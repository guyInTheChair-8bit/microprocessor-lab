# Experiment 2: AVR Peripherals

This exercise covers wiring AVR peripherals and controlling inputs and outputs through assembly, including LEDs, push buttons, and DIP switches.

The extracted examples are split by task: `task_01_led_blink.asm`, `task_02_push_button_led.asm`, `task_03_nibble_addition.asm`, and `task_04_dip_switch_adder.asm`. `nibble_addition_original.asm` preserves the earlier source for Task 3, and `gpio_peripheral_setup.asm` is an additional port setup example. The assembly files target the ATmega8 and require the Microchip `m8def.inc` include file. The handout and original report remain local and are excluded from Git.
