# Experiment 1: AVR Assembly Emulation

This exercise introduces arithmetic and logical operations in AVR assembly for the ATmega8. `task_01_add_8_bit_numbers.asm` implements the handout's 8-bit addition task: the sum is left in `R16`, and the carry flag records overflow.

The nibble-addition source belongs to AVR Experiment 2 and is stored there. The experiment handout PDF is kept locally and is excluded from Git.
