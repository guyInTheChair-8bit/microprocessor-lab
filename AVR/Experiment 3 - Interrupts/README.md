# Experiment 3: AVR Interrupts

This exercise introduces interrupt handling on an AVR ATmega microcontroller and the structure of an interrupt service routine.

`task_01_external_interrupt_blink.asm` is the code extracted from the report. It configures INT1 and blinks the LED ten times from the ISR. The original `external_interrupt_isr.asm` example is also retained. The handout and report remain local and are excluded from Git.
