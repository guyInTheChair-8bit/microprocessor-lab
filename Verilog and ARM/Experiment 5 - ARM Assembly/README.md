# Experiment 5: ARM Assembly

This exercise introduces ARM assembly instructions, data loading, arithmetic, addressing, and multiple-register transfers using Keil µVision. The report's code is separated by task into `task_01_move_immediate.s`, `task_03_load_constant.s`, `task_04_add_words.s`, `task_05_add_64_bit_values.s`, `task_06_fibonacci.s`, `task_07_load_indexed_word.s`, and `task_08_load_multiple.s`. The report did not contain a code block for Task 2. The handout and report remain local and are excluded from Git.
