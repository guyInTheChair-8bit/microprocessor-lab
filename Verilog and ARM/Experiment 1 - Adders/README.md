# Experiment 1: FPGA Adders

This FPGA exercise progresses from a half-adder to a full-adder and a four-bit ripple-carry adder. The extracted modules are `half_adder.v`, `full_adder.v`, and `ripple_carry_adder.v`; their testbenches are in matching `*_tb.v` files. The ripple-carry design instantiates `fulladd`, so compile both source modules together. The report and handout PDFs remain local and are excluded from Git.
