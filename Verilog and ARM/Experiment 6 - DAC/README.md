# Experiment 6: ARM Digital-to-Analog Conversion

This exercise uses the LPC2148's DAC to convert generated digital samples into analog waveforms for observation on an oscilloscope. The extracted files are separated by task: `task_01_dac_init.c` configures the DAC pin, `task_02_delay.c` provides the delay fragment, and Tasks 3 and 7 generate sine and triangular waves. `task_06_square_wave.c` remains available locally but is excluded from Git. Each waveform program is self-contained and uses the LPC214x device header. The handout and original report remain local and are excluded from Git.
