# Experiment 2: Flip-Flops and Johnson Counter

This FPGA exercise uses D flip-flops, including a resettable version, to build a three-bit Johnson counter. It also covers a clock divider and seven-segment decoder for displaying the counter state.

The Verilog sources in this folder implement the flip-flops, counter, clock divider, and decoder. The experiment handout PDF is kept locally and excluded from Git.
