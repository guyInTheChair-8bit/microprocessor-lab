# Experiment 4: High-Level Synthesis

This exercise introduces high-level synthesis as a way to turn algorithmic C/C++ descriptions into FPGA hardware. The task mapping follows the handout: Task 1 is the fixed-weight OR perceptron (`or_gate.h`, `or_nn.cpp`, `or_nn_tb.cpp`); Task 2 is the trained NAND perceptron (`nand_gate.h`, `nand_nn.cpp`, `nand_nn_tb.cpp`). The source files are not swapped. The report text has OCR-damaged code, so the separate source files are the clean versions to use.

The NAND and OR examples and their testbenches are included with the handout. The HLS sources do not add explanatory code comments. The handout and original report remain local and are excluded from Git.
